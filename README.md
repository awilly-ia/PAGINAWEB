# 🗺️ Maison WM - Alta Perfumería

## 🔍 Descripción
**Maison WM** es el desarrollo de un sitio web ficticio dedicado a la alta perfumería de lujo. El concepto visual y la identidad de la marca están inspirados en la estética clásica, elegante y detallada de la casa británica *Penhaligon's*. 

El proyecto ha sido construido utilizando estándares modernos de desarrollo web, implementando una estructura semántica limpia mediante el uso de etiquetas de **HTML5** (`<header>`, `<nav>`, `<section>`, `<aside>`, `<article>` y `<footer>`) y un diseño estilizado con **CSS** para garantizar una experiencia de usuario atractiva y organizada.
